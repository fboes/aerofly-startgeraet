# ![](../assets/icons/icon.svg) Aerofly Startgerät - Mission Generator general instructions

The GUI app as well as the CLI tool version of the Aerofly Startgerät feature a mission generator. This will use the current settings of the simulator (e.g. aircraft, time, date, weather, origin airport) and will create a new flight plan.

Depending on the mission generator used, a dialog will let you configure mission parameters.

Keep in mind that some limitations still exist, like setting up a correct starting position or fuel load.
