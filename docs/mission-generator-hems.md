# ![](../assets/icons/icon.svg) Aerofly Startgerät - Helicopter Emergency Medical Services Mission GeoJSON Files

The Aerofly Startgerät HEMS mission generator needs a [POI Creator Tool (PCT) JSON file](https://github.com/jlgabriel/afs4-poi-creator), containing all possible locations to be used for mission generation. Creating such a file is explained in the [PCT guide](https://github.com/jlgabriel/afs4-poi-creator/blob/main/guide/GUIDE.md).

As the PCT is primarily used to place objects, lights and other Points of Interest (POI) in Aerofly FS, you will have the opportunity to also place the objects required for your mission.

## Directory

The PCT JSON file must be paced in the regular Aerofly POI directory. Usually this is a sub-directory of your Aerofly user directory, called `scenery/poi`.

In this directory another folder needs to be created for the HEMS mission generator, which finally contains the PCT JSON file. The name of the directory must be contain the coordinates as required by Aerofly (automatically created by the PCT), `startgeraet-hems-`, and the ICAO code of the airport you will be starting from.

Examples:

- `e01046n5325_startgeraet-hems-EDHG`
- `w00540n5646_startgeraet-hems-EGEO`
- `w12251n3778_startgeraet-hems-CN02`

This directory must contain at least one `.json` file generated by the PCT, containing the actual location information.

## Locations

The mission generator will search the PCT JSON file for locations. The HEMS mission generator uses these types of locations:

- **Heliports** set the stating position of your aircraft. The direction of the location will be the initial heading of your aircraft. If the heliport does not natively exist in Aerofly FS, it is a good idea to at least provide a helipad with appropriate lighting.
- **Hospitals** will be the location you will need to get to after leaving an emergency site. If multiple hospitals exists, the hospital nearest to the emergency site will be used. If the hospital helipad does not natively exist in Aerofly FS, it is a good idea to at least provide a helipad with appropriate lighting.
- All other locations are considered to be **emergency sites**. Per mission one emergency site will be picked at random. Most often these locations are represented by an ambulance vehicle with a flashing red / blue light.

Each location you want to show up in the mission generator needs an POI object with a **label** set via the PCT. Objects _without_ labels will be ignored by the mission generator, and will not be used as locations for mission generation.

A label consists of the **name** of the location, followed by optional **tags**. Each tag starts with a `#`, and is separated by a white-space from the next tag.

The following tags exist:

| Tag                      | Example         | Description                                          |
| ------------------------ | --------------- | ---------------------------------------------------- |
| `heliport`               |                 | This location is a heliport / helipad                |
| `#hospital`              |                 | This location is a hospital                          |
| `#icao:` + ICAO Code     | `#icao:CN02`    | ICAO code / flight plan identifier for this location |
| `#approach:` + direction | `#approach:253` | Approach directions, multiple tags may be added      |

Here are some examples for labels, with location name and tags:

| Label                                                               | Description                                                   |
| ------------------------------------------------------------------- | ------------------------------------------------------------- |
| "Golden Gate Vista Point"                                           | Emergency site                                                |
| "San Francisco VA Medical Center #hospital #heliport #icao:CN02"    | Heliport as well as hospital landing pad, ICAO code is "CN02" |
| "Lüneburg airfield #heliport #icao:EDHG #approach:73 #approach:253" | Heliport with ICAO code EDHG, approaches from 73° and 253°    |
